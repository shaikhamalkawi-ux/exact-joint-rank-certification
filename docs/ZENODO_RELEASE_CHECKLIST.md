# Zenodo release checklist

The GitHub repository is public. Use this checklist when you are ready to create a permanent archived software release.

1. Replace the placeholder contributor entry in `CITATION.cff` with the final author list.
2. Add the final paper DOI/URL when available.
3. Connect this GitHub repository to Zenodo.
4. Create a versioned GitHub release (recommended first archival tag: `v1.0.0`).
5. Let Zenodo archive the release and mint a DOI.
6. Add the Zenodo DOI to `CITATION.cff` and README.
7. If permitted by the venue, add the DOI/repository link to the final manuscript or supplementary material.
8. Freeze the release used by the paper; future development should occur in later versions.
